TAJ GIFTS - READ THIS FIRST
===========================

1. Right-click the zip, "Extract All", choose a folder.
2. Open the folder, double-click DEPLOY.bat
3. Wait about 2 minutes. Netlify rebuilds from GitHub.

Verify: https://tajgifts.netlify.app/api/app/auth
Expect: {"ok":true,"service":"Taj Gifts native account API"}

The .git folder is already inside this package - do not delete it.
The live site does not use .env.local; keys live in Netlify.
