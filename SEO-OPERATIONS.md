# Taj Gifts SEO & local-search operations

This project is configured to earn relevant organic visibility for searches such as **gift hampers**, **gift hampers Kashipur** and **gift hampers Uttarakhand**. It cannot honestly guarantee a #1 position: search rankings depend on competition, relevance, location, quality signals and Google’s own systems.

## Technical foundation included in the release

| Area | Included implementation |
|---|---|
| Canonical indexing | Canonical metadata, `robots.txt`, `/sitemap.xml`, site metadata and HTTPS-ready deployment configuration |
| Local landing pages | `/gift-hampers-kashipur` and `/gift-hampers-uttarakhand`, with non-duplicative local content, internal product links and clear delivery caveats |
| Structured data | Website/business, breadcrumbs, FAQ, collection and factual product schema; no aggregate rating is emitted unless approved review data exists |

## Deployment-day SEO checklist

1. Deploy the source using the procedure in `PRODUCTION-RELEASE.md`.
2. Set `NEXT_PUBLIC_SITE_URL` to the one canonical HTTPS domain. Do not leave it pointing at a staging/old domain.
3. Confirm these resolve with `200` responses and self-referencing canonicals:
   - `/`
   - `/shop`
   - `/gift-hampers-kashipur`
   - `/gift-hampers-uttarakhand`
   - `/policies`
   - `/sitemap.xml`
   - `/robots.txt`
4. In Google Search Console, verify the domain/property and submit:

   ```text
   https://<canonical-domain>/sitemap.xml
   ```

5. Use Search Console URL Inspection after deployment for the homepage and both local landing pages. Request indexing only after verifying production content.

## Local SEO: owner actions

### Confirm one exact public NAP record first

Before creating or editing citations, decide the customer-facing business identity:

```text
Business name: Taj Gifts
Phone: +91 76688 19833
Website: https://<canonical-domain>
Address/service-area: owner-confirmed single version
Hours: owner-confirmed real hours
```

The current live setting and an older public profile mention different Kashipur area descriptions. Do not spread both. Confirm one real studio/customer-contact address, or use a properly configured service-area profile if customers are not received at the studio.

### Google Business Profile

- Use the exact verified name, category, phone, website, hours and physical/service-area information.
- Add genuine current photographs: exterior/entry only if customers can visit, otherwise real preparation area/product shots; named product photos; packaging; seasonal work.
- Add real product/service entries that match public website pages and prices.
- Link the profile to the canonical home page or relevant Kashipur collection page.
- Do not create a false storefront, keyword-stuff the business name, use virtual offices or invent service areas.

### Citations and links

- Update only credible profiles you genuinely operate: the existing social channel, Google Business Profile, relevant reputable local directories and legitimate supplier/event-partner mentions.
- Keep NAP, URL and hours identical everywhere.
- Build links through useful local relationships and content (real event planners, wedding vendors, corporate gifting partners, community/seasonal features), not paid link farms.

## Content cadence that supports these searches

Publish only content the business can substantiate. Good examples:

- a seasonal collection page that names actual available hampers and delivery cutoff dates;
- a detailed wedding-return-gift or corporate-bulk page with genuine minimums, lead time and enquiry route;
- a Kashipur gifting guide that helps customers choose, without pretending to cover unavailable localities;
- original product photographs, contents, variant/add-on information and care/allergen notes where applicable;
- post-delivery, order-linked review requests that invite honest feedback without incentives or review gating.

Avoid thin city-page duplication, copied manufacturer copy, fake testimonials, invented ratings, “#1” claims, hidden text and unsupported same-day/delivery guarantees.

## Monthly measurement

Track in Search Console and the business’s analytics platform:

- impressions, clicks, average position and click-through rate for Kashipur/Uttarakhand gift-hamper query variants;
- indexed-page coverage and crawl errors;
- landing-page performance for the two local pages;
- genuine enquiry/order conversion, not only traffic;
- review volume and rating only when verified, moderated customer feedback exists.

Review product stock, prices, offers, holiday delivery capacity and local landing-page copy before each festival campaign so search snippets remain accurate.
